# FocusFlow Mobile

This folder contains a Flutter-first starter structure created without the Flutter SDK. The file layout mirrors the product architecture so that `flutter create .` can be introduced later with minimal reshuffling.

## What is included

- A feature-first `lib/` structure
- A tabbed app shell for Home, Focus, Analytics, Insights, and Settings
- Shared theme and UI pieces
- Domain entities for dashboard snapshots and focus sessions

## What is missing

- Generated Flutter platform folders
- Dependency lock files
- Running validation from `flutter analyze` or `flutter test`

Install Flutter, run `flutter create .`, then merge the generated files with this scaffold.
